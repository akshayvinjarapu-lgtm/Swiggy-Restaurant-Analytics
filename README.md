# Swiggy Restaurant Analytics Project

## Project Overview
This project analyzes Swiggy restaurant data to identify restaurant trends, customer ratings, pricing patterns, and cuisine insights using SQL and Power BI.

## Tools & Technologies
- MySQL
- Power BI
- SQL
- Data Cleaning
- Data Visualization

## Key Analysis
- Total Restaurants
- Average Restaurant Rating
- City-wise Restaurant Distribution
- Rating Distribution
- Restaurant Cost Distribution
- Restaurant Cost vs Rating Analysis
- Cuisine-wise Average Cost
- Top-rated Cities

## Dashboard
The Power BI dashboard provides interactive visualizations with City and Price Range filters.

## SQL Analysis
SQL queries are used for data exploration, analysis, aggregation, and business insights.
